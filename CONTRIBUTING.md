# Contributing to ai-security-ops-alan-vo

## Setup
```bash
git clone https://github.com/ALANDVO/ai-security-ops-alan-vo.git
cd ai-security-ops-alan-vo
pip install -r requirements.txt
cp .env.example .env
```

## Code Style
- Python 3.10+, type hints, docstrings
- TypeScript strict mode for frontend
- No hardcoded secrets

## Submitting Changes
1. Fork → feature branch → test → PR
2. Include: what changed, why, how to test

## Issues
- Steps to reproduce
- Expected vs actual
- Log output (redact keys)
